# دليل نظام تراخيص FluxWAN المشفر (Ed25519 Cryptographic Licensing Guide)

يقدم هذا الدليل شرحاً تفصيلياً لكيفية إدارة وتوليد مفاتيح الترخيص لنظام **FluxWAN Carrier-Grade Multi-WAN Router**، سواء لاشتراكات محددة بعدد أيام أو تراخيص مفتوحة مدى الحياة (Lifetime)، مع تفصيل آليات الحماية والتشفير غير القابلة للكسر أو التخطي.

---

## 1. المعمارية الأمنية والتشفيرية (Uncrackable Security Architecture)

تم تصميم نظام التراخيص في FluxWAN وفق نموذج الحماية اللامركزية المعزولة (Air-Gapped Cryptographic Licensing):

```
+------------------------------------------------------------------------------------+
|                         FluxWAN Multi-Layer Licensing                              |
+------------------------------------------------------------------------------------+
| 1. تشفير غير متماثل Asymmetric Ed25519 (RFC 8032):                                 |
|    - مفتاح المطور الخاص (Master Private Key) يبقى حصرياً في جهاز المطور.             |
|    - المفتاح العام (Master Public Key) مدمج داخل كود C في الراوتر.                 |
|    - لا يمكن لأي طرف أو قرصان توليد مفتاح صالح رياضياً بدون المفتاح الخاص.          |
|                                                                                    |
| 2. ربط بصمة العتاد الفيزيائي Hardware Fingerprint (Anti-Cloning):                  |
|    - مشتق من SHA-256(DMI UUID + Disk Serial + CPU Machine-ID + Internal Salt).     |
|    - صيغة المعرف: FWID-XXXX-XXXX-XXXX-XXXX.                                        |
|    - المفتاح المرخص لراوتر معين يستحيل تشغيله على راوتر آخر أو آلة افتراضية منسوخة.  |
|                                                                                    |
| 3. منع التلاعب بالساعة وتغيير الوقت (Anti-Clock Rollback):                         |
|    - سجل زمني تراكمي (.lic_watermark) يسجل أحدث وقت عمل للنظام.                     |
|    - إذا حاول العميل إرجاع ساعة السيرفر أو تزييف NTP بأكثر من 5 دقائق، يتحول النظام   |
|      فوراً إلى حالة CLOCK_TAMPERED ويتوقف التوجيه.                                  |
|                                                                                    |
| 4. تشابك نواتي عميق Functional Kernel Interlocking:                                |
|    - فحص الترخيص متداخل في دورة توازن الخطوط wan_manager_rebalance وخرائط eBPF.     |
|    - في حالة عدم وجود ترخيص أو انتهاء الصلاحية: يتم تصفير أوزان الـ WANs وتجميد    |
|      تمرير الحزم بالكامل.                                                          |
|                                                                                    |
| 5. فترة سماح أولية Grace Period (30 دقيقة):                                        |
|    - تمنح عند أول إقلاع للجهاز لإتاحة الدخول إلى لوحة التحكم وتفعيل المفتاح.        |
+------------------------------------------------------------------------------------+
```

## 2. كيفية توليد التراخيص للعملاء (Developer Licensing CLI)

توجد أداة توليد التراخيص الرسمية في المسار `tools/fluxwan_license_gen.py`. تعمل الأداة على أي نظام يدعم بايثون 3 (Linux, WSL, macOS, Windows).

### أ. استخراج بصمة العتاد (Hardware ID) للعميل
1. يقوم العميل بالدخول إلى لوحة تحكم FluxWAN Web UI (`http://192.168.90.1:8080`).
2. الانتقال إلى تبويب **"🔑 الترخيص والحماية" (License & Security)** في القائمة الجانبية.
3. الضغط على زر **"نسخ البصمة" (Copy HWID)** بجانب معرّف الجهاز (مثال: `FWID-F831-141C-52BE-3089`).

---

### ب. إنشاء ترخيص بعدد أيام (مثلاً 30 أو 90 أو 365 يوماً)
```bash
python3 tools/fluxwan_license_gen.py \
  --hwid "FWID-XXXX-XXXX-XXXX-XXXX" \
  --client "Baghdad Telecom Node 1" \
  --type days \
  --days 90
```

**النتيجة**:
```
======================================================================
      FluxWAN Official Cryptographic License Key (Ed25519)      
======================================================================
 Client Name  : Baghdad Telecom Node 1
 Hardware ID  : FWID-XXXX-XXXX-XXXX-XXXX
 License Type : DAYS
 Duration     : 90 Days
 Max WANs     : 256
----------------------------------------------------------------------
 LICENSE KEY (Send this to the customer):

FLUX-LIC-RkxJQwEBAAHWq79qAAAAAFbfoGwAAAAAbQEAAEZXSUQt...
======================================================================
```

---

### ج. إنشاء ترخيص مفتوح مدى الحياة (Lifetime)
```bash
python3 tools/fluxwan_license_gen.py \
  --hwid "FWID-XXXX-XXXX-XXXX-XXXX" \
  --client "Al-Basrah Fiber Backbone" \
  --type lifetime
```

**النتيجة**:
```
======================================================================

======================================================================
 Client Name  : Al-Basrah Fiber Backbone
 Hardware ID  : FWID-XXXX-XXXX-XXXX-XXXX
 License Type : LIFETIME
```

## 3. تطبيق سطح المكتب الرسومي (FluxWAN License Studio — Desktop GUI)

لتوليد التراخيص بنقرة واحدة وبدون الحاجة لكتابة أي أوامر، تم بناء برنامج سطح مكتب رسومي احترافي متكامل:
- **الملف التنفيذي المستقل**: `FluxWAN-License-Studio.exe` (موجود في مجلد المشروع وعلى سطح المكتب لديك `Desktop\FluxWAN-License-Studio.exe`).
- **المشغل السريع**: `FluxWAN-License-Studio.bat`.

### مميزات تطبيق سطح المكتب:
1. **واجهة رسومية داكنة (Modern Dark Theme)**: مريحة للعين ومتوافقة مع تصميم لوحة تحكم FluxWAN.
2. **لصق البصمة بنقرة واحدة**: زر مخصص "📋 لصق من الحافظة" للصق الـ HWID المنسوخ من العميل فوراً.
3. **خطط سريعة جاهزة**:
   - ⚡ شهر واحد (30 يوماً)
   - ⚡ 3 أشهر (90 يوماً)
   - ⚡ 6 أشهر (180 يوماً)
   - ⚡ سنة كاملة (365 يوماً)
   - 👑 مفتوح مدى الحياة (Lifetime)
   - ⏳ عدد أيام مخصص (Custom Days)
4. **توليد مشفر فوري**: توقيع تشفيري عسكري بمفتاح Ed25519 الخاص في أجزاء من الثانية.
5. **نسخ وحفظ بنقرة واحدة**:
   - زر "📋 نسخ كود المفتاح كاملاً" لنسخ الكود ومشاركته مع العميل.
   - زر "💾 حفظ في ملف نصي (.txt)" لأرشفة ترخيص العميل باسم شبكته.

## 4. كيفية التفعيل في جهاز الراوتر (Activation Process)

### الطريقة 1: عبر واجهة الويب (Web UI) — موصى بها
1. الدخول إلى لوحة التحكم `http://192.168.90.1:8080/`.
2. النقر على **"الترخيص والحماية"** من القائمة.
3. لصق كود المفتاح الكامل (يبدأ بـ `FLUX-LIC-...`) في حقل النص.
4. النقر على زر **"تفعيل الترخيص فوراً"**.
5. ستظهر رسالة نجاح خضراء، وتتحول الشارة العلوية إلى 🟢 **نشط** أو 🟢 **مرخص مدى الحياة** مع إظهار اسم العميل وعدد الأيام المتبقية لحظياً.

### الطريقة 2: عبر موجه الأوامر / الطرفية (CLI / File)
يمكن حفظ كود المفتاح مباشرة في ملف الترخيص الرسمي:
```bash
echo "FLUX-LIC-..." > /opt/fluxwan/config/license.key
```
ثم إعادة تشغيل الراوتر أو إرسال طلب REST API:
```bash
curl -X POST http://127.0.0.1:8080/api/v1/license/activate \
  -H "Content-Type: application/json" \
  -d '{"license_key": "FLUX-LIC-..."}'
```

---

## 4. مسارات الـ REST API

| المسار | الطريقة | الوظيفة |
|---|---|---|
| `/api/v1/license` | `GET` | استعلام تفاصيل الترخيص: البصمة، الحالة، الأيام المتبقية، العميل، والنوع. |
| `/api/v1/license/activate` | `POST` | إرسال مفتاح الترخيص وتفعيله تشفيرياً على مستوى النواة. |

## 5. الحماية ضد محاولات الكسر (Tamper-Resistance Summary)
- **تعديل الملف التنفيذي (Hex Editing / Patching)**: كود التحقق مكتوب بلغة C النقية المدمجة مع النواة، بدون أي مكتبات ديناميكية خارجية قابلة للاستبدال (No external dynamic shared objects for crypto).
- **التشغيل على جهاز آخر**: تفشل المصادقة فوراً لعدم تطابق البصمة HWID المشفرة داخل التوقيع الرقمي.
- **تعديل نص المفتاح**: يؤدي إلى فشل فوري في التحقق الرياضي لمنحنى Ed25519 ويرفض المفتاح كلياً.
- **إرجاع وقت النظام**: يكتشفه محرك العلامة المائية `.lic_watermark` ويغلق التوجيه تلقائياً كإجراء دفاعي.
