# Target: MikroTik RB750Gr3 / RB760iGS (hEX / hEX S)

## Specifications:
- **Architecture**: MIPS (mips32r2) - MediaTek MT7621AT (2 Cores / 4 Threads @ 880MHz)
- **RAM**: 256MB DDR3
- **Flash**: 16MB SPI NOR Flash
- **Switch**: MT7621 Built-in Gigabit Switch (5x 1G Ports)
- **Bootloader**: RouterBOOT (Netboot / TFTP via `initramfs-kernel.bin`)
